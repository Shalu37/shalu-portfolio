# Shalu Jawla Portfolio — React

Converted from the original single HTML file into a React + Vite project.

## Features

- React component architecture
- Separate CSS file
- Portfolio content stored in `src/data/portfolio.js`
- Responsive navigation
- Scroll progress bar
- Scroll reveal animations
- Interactive architecture diagram
- Experience highlighting
- Project filtering with localStorage persistence
- Animated skill bars
- Interactive terminal
- Copy-email interaction
- Reduced-motion accessibility support
- Lucide icons
- Vite production build

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually:

`http://localhost:5173`

## Production test

```bash
npm run build
npm run preview
```

The original portfolio content and claims are preserved from the supplied HTML; update `src/data/portfolio.js` when your real resume/projects change.
